# Contributing to VS Code SFTP Plugin

## Getting Started

1. Fork the repository on GitHub
2. Clone your forked repository to your local machine:
   ```bash
   git clone https://github.com/your-username/sftp-plugin.git
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Make sure you have **Node.js** and **npm** installed

## Development

- Use `npm run dev` to start the extension in development mode
- Use `npm run test` to run the unit tests
- Use `npm run build` to build the extension
- Use `npm run package` to package the extension for publishing

## Code Style

- Follow **Prettier** and **ESLint** guidelines
- Use **TypeScript** for all new code
- Keep **test coverage** high

## Pull Requests

- Submit a **pull request** with your changes
- Ensure all **tests pass**
- Add **unit tests** for new features
- Follow the **coding guidelines**
- Use **descriptive commit messages**

## Reporting Issues

- Use the **GitHub Issues** tracker to report bugs or feature requests
- Include **steps to reproduce** any issues
- Provide **screenshots or logs** if applicable
